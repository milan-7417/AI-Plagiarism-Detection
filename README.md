# Semantrix

AI-Powered Plagiarism and Paraphrase Detection System.

## Features

- PDF, DOCX and TXT document extraction
- Pretrained BERT embeddings
- Cosine similarity calculation
- Advanced sentence matching
- Document-level similarity analysis
- Lexical and semantic classification
- Visual sentence comparison
- CSV report generation

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- BERT Base Uncased
- Gradio
- Pandas
