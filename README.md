# Semantrix

AI-powered document similarity and paraphrase detection using pretrained BERT Base.

## Features

- PDF, DOCX and TXT document support
- Sentence-level semantic similarity
- Exact and near-exact match detection
- Potential paraphrase identification
- Similarity analysis and document coverage
- Visual sentence comparison
- Downloadable comparison reports

## Model

google-bert/bert-base-uncased

## Disclaimer

Similarity scores indicate textual similarity, not confirmed plagiarism. Results require human review.
